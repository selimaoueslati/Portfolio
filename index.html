CYBERSECURITY INTERNSHIP · 3S · 2026

Beyond segmentation and IAM, I built a live SOC dashboard that pulls real status from Docker, Keycloak, OPNsense, PostgreSQL and Wazuh — then runs every access request through a custom policy engine that scores risk in real time and explains, in plain language, why it allowed or denied it.

OPNsense Keycloak Docker IAM / RBAC / MFA PostgreSQL Wazuh SIEM

ZERO TRUST / THE DECISION ENGINE every access request, scored and explained

Same user, four contexts. The policy engine checks identity, role, device trust and MFA, then computes a risk score from 0 to 100 and decides — with a reason a human can actually read.

PROOF, NOT JUST DISPLAY

Every decision above is written to PostgreSQL and streamed to Wazuh as a JSON event — nothing on this dashboard is faked or hardcoded.

One detail I'm proud of: an Admin account correctly bypasses the role check on purpose — the engine respects privilege hierarchy instead of blindly denying everyone the same way.
